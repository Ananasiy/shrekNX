# shrekNX

Экспериментальный homebrew-порт **Shrek 2 для PC (KnowWonder, 2004)** на Nintendo Switch. Нативные x86-модули игры статически переводятся в C и собираются для ARM64; Win32, Direct3D 8, ввод и звук обслуживает слой совместимости. macOS на Apple Silicon используется для разработки и проверки.

В репозитории — код порта, рекомпилятор и инструменты. **Для сборки и запуска нужна собственная совместимая копия PC-игры.** Файлы игры, сгенерированный из них C-код, обложки и готовые игровые NRO здесь не распространяются.

## Состояние

**Версия 0.2.0** ([изменения](CHANGELOG.md)). Игра запускается на настоящей Switch: работают меню, первый уровень, звук, ролики, управление геймпадом с легендой кнопок и Quick Menu, вибрация и сохранения. Полное прохождение и визуальная сверка с оригиналом ещё не подтверждены; Linux — `[проверить]`.

| Возможность | Что проверено |
|---|---|
| Switch | 0.2.0: проверено в портативе (1280×720, полный режим памяти): меню 60 FPS, ролики 50–60 FPS (потоковый Bink), болото 43–60 FPS, сохранение 634 мс, шрифт оверлея `pl:u` и легенда, скрытие настроек ПК после загрузки уровня, вибрация при уроне и ударах, подсказка в applet-режиме; хуки HOME/сон/док, гамма и повторный запуск с кешем бинарников GL — `[проверить]` |
| Производительность | 0.1.0 на Switch: 38,0–38,8 FPS у точки сохранения в болоте при CPU 1020 МГц, с локальным профилем PGO (одна сцена); на 0.2.0 в портативе наблюдалось 43–60 FPS (режим/частота не фиксировались — формальный замер `[проверить]`) |
| macOS arm64 | Меню (опциональный 4:3 pillarbox, легенда кнопок, Quick Menu), болото, `3_The_Hunt_Part4`, звук и ролики; 12 CTest (включая ASan+UBSan) и 20 тестов рекомпилятора |
| Linux | Поддержка CMake/OpenGL/POSIX и CI `linux-arm64` (`-DSNX_PIN=ON`) добавлены — сборка и запуск `[проверить]` |
| Русская версия | Отдельная сборка из DLL локализации «Новый Диск»; кириллица поддержана в оверлее и Quick Menu; проверка на Switch после последних изменений — `[проверить]` |

Остаются фризы при первом появлении материалов (до заполнения кеша программ) и сохранении, растянутый по ширине 2D HUD во время игры (для страниц меню доступен опциональный режим 4:3 в Quick Menu) и проверка полного прохождения на Switch. Профиль PGO не входит в репозиторий: обычная сборка может работать медленнее указанного замера.

## Сборка

Пошаговая инструкция: **[docs/BUILDING.md](docs/BUILDING.md)**. Основная среда разработки — macOS arm64 (также добавлена конфигурация для Linux, `[проверить]`); для Switch дополнительно нужен devkitPro.

После установки зависимостей, из корня репозитория:

```sh
python3 -m venv tools/.venv
tools/.venv/bin/python -m pip install -r tools/requirements.txt
tools/build.sh mac
ctest --test-dir build/mac --output-on-failure
```

Без игры собираются GL-пример, рантайм и самостоятельные тесты. Для игрового хоста сначала нужен перевод модулей:

```sh
tools/.venv/bin/python -I recomp/main.py gen --game game/System --out build/gen
tools/build.sh mac snx_boot
build/mac/host/boot/snx_boot --game game --user build/userdata
```

Для Switch после настройки devkitPro:

```sh
tools/build.sh switch snx_boot_nro
```

Результат — `build/switch/host/boot/snx_boot.nro`. Файлы той же игры должны находиться в `sdmc:/switch/shrek2/game/`. Подробности первого запуска, русской версии и ошибок CRC — в инструкции сборки.
